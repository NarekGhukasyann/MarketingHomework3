# Homework 3 - Survival Analysis

This project analyzes churn risk and customer lifetime value (CLV) using survival analysis techniques on the Telco dataset.

## Contents

- Data preprocessing and survival variable definition
- Fitting parametric AFT models (Weibull, Log-Normal, Log-Logistic)
- Model comparison and selection
- Coefficient interpretation and segment analysis
- CLV calculation and exploration across customer segments
- Retention budget estimation and strategic recommendations

## Requirements

Install packages using:

```
pip install -r requirements.txt
```
